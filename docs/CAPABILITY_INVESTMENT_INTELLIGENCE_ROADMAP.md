# Capability Investment Intelligence Roadmap

This roadmap item is an architectural principle, not an active cognitive layer.

Capability Investment Intelligence may answer:

- Which capabilities deserve more validation opportunities?
- Which capabilities deserve more compute allocation?
- Which elite validation tasks should be prioritized?
- Which capability investments have the highest expected cognitive ROI?

It must never answer:

- Which validation outcomes are true?
- Which capabilities deserve higher trust scores?
- Which capabilities graduate?
- Which governed validation contracts are satisfied?
- Which truths are accepted by NEXRYN?

Canonical boundary:

```text
Capability Investment Intelligence
→ allocation only

Governed Validation
→ evidence validity

Trust Formation
→ trust score formation

Graduation Governance
→ capability advancement
```

Core principle:

```text
High ROI is not higher truth.
Investment allocates validation opportunities only.
Evidence forms trust.
```

Long-term sequence:

```text
Capability Discovery
↓
Capability Validation
↓
Capability Promotion
↓
Trust Formation
↓
Graduation Intelligence
↓
Operational Capability Population
↓
Capability Economy
```
