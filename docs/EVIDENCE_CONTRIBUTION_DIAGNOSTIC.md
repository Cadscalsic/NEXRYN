# Evidence Contribution Diagnostic

Evidence sufficiency now reports the relative contribution and remaining
deficit for each evidence family. This is a reporting diagnostic only; it does
not change validation requirements, trust scores, promotion decisions, or
graduation authority.

Evidence families:

```text
ground_truth
independent_validation
operational_reuse
stability
cross_domain
operational
graduation_specific
```

The report also identifies:

```text
Highest Remaining Evidence Deficit
Highest Remaining Evidence Deficit Action
```

Purpose:

```text
Move from "more evidence is needed"
to "this specific evidence family is the next deficit."
```
