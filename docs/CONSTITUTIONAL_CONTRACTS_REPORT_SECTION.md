# Constitutional Contracts Report Section

The final NEXRYN report includes a `CONSTITUTIONAL CONTRACTS` section as a
reporting consolidation only. It does not add a runtime layer, governance layer,
or validation subsystem.

The section exists to keep immutable architectural boundaries visible near the
top of the report, especially when the console report is truncated.

Canonical contracts:

```text
TRUTH_IS_EVIDENCE_GOVERNED
TRUST_IS_EVIDENCE_GOVERNED
GRADUATION_IS_EVIDENCE_GOVERNED
INVESTMENT_NEVER_INFLUENCES_TRUTH_FORMATION
VALIDATION_SPONSORSHIP_NEVER_INFLUENCES_TRUST_FORMATION
```

Evidence sufficiency question:

```text
when_is_evidence_sufficient_for_trust_update_and_graduation
```

This question is diagnostic. It does not alter validation outcomes, trust
scores, promotion decisions, or graduation authority.
